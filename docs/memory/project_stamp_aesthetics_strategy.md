All passport stamps in nieves-kitchen follow a shared **ink-impression-on-transparent** grammar except three anchor aesthetics (Western Europe, Eastern Europe, East Asia) and one alternate grammar (**Cabinet etching**, used by Mesoamerica + Caribbean from 2026-05-17 onward — see below). Default grammar: frame is outline only with no substrate inside the silhouette, two ink colors per stamp, rubber-stamp imperfection specified explicitly, country name in Latin display serif + optional one-line native script in smaller weight.

**Cabinet etching alternate grammar (2026-05-17):** Adopted to introduce visual rhythm across the booklet so the 100+ stamps don't read as variations on a single frame. Inspired by real engraved-vignette passport stamps (e.g., Peruvian Machu Picchu visa). Single-ink only, no outer cartouche (illustration itself bounds the stamp), full-bleed fine-line engraved vignette with cross-hatching for tonal depth, arched serif title text wraps the top, bold sans-serif country name slab underneath. Per-country distinctiveness from the illustration subject, not from a border textile. **No 2-layer enrichment** (corner glyphs + horizon strip) — density baked into the hatching. Assigned to Mesoamerica (Maya blue / deep indigo ink, Cochineal red cancellation) and Caribbean (colonial sepia ink, indigo cancellation). Full grammar definition in `docs/stamps/SPEC.md` §6 below the regions table.

**Why:** Started as 13 region aesthetics (one cohesive theme per culinary region from `COUNTRY_TO_REGION` in `lib/regions.ts`). After the 2026-05-11/12 redesigns established the ink-impression grammar across 11 sub-regions, the 2026-05-15 sweep extended scope to also redo Southeast Asia (originally "manually authored, skipped") because existing SE Asia stamps were too dark and fabric-textured. USA's centre motif was changed from cast-iron skillet → diner coffee mug + pie wedge in the same sweep (form unchanged — engraved postage cartouche + sepia/barn-red two-tone). Canada kept its maple-syrup tap and its butter-yellow third ink (per user instruction to keep Canada exactly as-is).

**How to apply:** When generating or designing new stamps, use the per-region grammar below — never reintroduce substrate language (paper card, bark cloth, glazed tile, plaster, etc.) or 3+ tone palettes. Boilerplate (canvas instructions + universal negative prompt) is stripped from each core prompt in `docs/plans/2026-05-06-stamp-final-prompts.md` and lives in two labeled blocks at the top of that file (Boilerplate A for anchor sections 1 + 10; Boilerplate B for ink-impression sections 2, 3a, 3b, 4, 5, 6, 7, 8, 9, 11a, 11b, 12, 13). Specs in `docs/superpowers/specs/2026-05-11-*-design.md` and `docs/superpowers/specs/2026-05-12-*-design.md` (gitignored under `docs/superpowers/`). Source-of-truth precedence: `docs/stamps/SPEC.md` §6 > redesign specs > prompts file.

**Cancellation ink change 2026-05-15:** Sub-Saharan Africa cancellation ink moved from Terracotta → **Forest** (Coptic-jade tone) to avoid colliding with East Africa's savanna-terracotta primary visa ink. `--stamp-ink-forest` already exists in `app/globals.css`.

**Country-distinctiveness lives in:** border textile/motif vocabulary (per-country) + center motif (landmark or food-object). Native script appears only where the country uses a distinct non-Latin script or an accented spelling worth differentiating (e.g., MEXICO / MÉXICO, NEW ZEALAND / AOTEAROA).

**Universal rules baked into every prompt:**
- No human faces, no portrait sculpture, no ceremonial mask faces, no deity faces (see `feedback_no_faces_in_prompts.md`).
- No third accent color (Canada is the only documented exception).
- Rubber-stamp imperfection clause is non-negotiable: broken lines, dry-press patches, ink bleed at corners, faint off-register double-strike in the secondary color, edge wear on the frame.
- No textile/material language — heritage names the geometric vocabulary, never the substrate (see `feedback_no_material_language_in_stamp_prompts.md`).
