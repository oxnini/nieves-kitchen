When generating image-generation prompts for passport stamps (or related visual assets on nieves-kitchen), **no human faces in any prompt**. Use silhouettes, profile outlines that omit facial features, or abstract/geometric figures.

**Why:** User stated this explicitly as a universal rule when locking in Brazil's Christ the Redeemer motif: "make sure no face is shown, no prompt should have faces." Likely a combination of (a) image-gen models often render faces poorly, (b) editorial taste — the booklet's restrained-warm aesthetic doesn't want literal human portraits competing with food/architecture/textile motifs, and (c) avoiding cultural-representation pitfalls.

**How to apply (STRICT):**
- No human faces of any kind. **No masks either** — even ceremonial carved masks (Pende, Punu, Fang, Boruca, vejigante, hei-tiki) are excluded.
- No bronze/sculpture portraits (Benin bronze head, Sphinx, Moai face features, lamassu capitals).
- No religious-icon faces painted on architecture (Boudhanath stupa "Buddha eyes" — render the stupa without the eye motifs, or swap to a different landmark).
- For motifs that imply human figures (samba dancer, gaucho, Maasai warrior, Bedouin horseman, monk silhouette, etc.) — render as silhouette only with no facial features. Default to omitting figures entirely when feasible.
- Christ the Redeemer → silhouette only, back-view or distant skyline-scale.
- Beaded medallions / Adinkra symbols / Yoruba beadwork / pattachitra / thangka style → abstract geometric only when applied as patterns, even though some traditional examples include figurative content.
- **Animals in silhouette/profile are allowed** (giraffe, gorilla, tiger, kangaroo, kiwi, falcon, etc.) — the rule is about human/anthropomorphic faces and mask faces, not animal forms. Render in profile silhouette without facial detail emphasis.
